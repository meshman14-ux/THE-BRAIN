# THE BRAIN

My personal links hub (`JAY_CLAUDE_HUB`) — a single static page served via GitHub Pages.

**Live site:** https://meshman14-ux.github.io/JAY_CLAUDE_HUB/

## Edit

Everything lives in [`index.html`](index.html). To change a link, edit its
`href` and label. Add or remove `<li>` blocks in the `.links` list. No build
step — commit and push, and GitHub Pages redeploys automatically.

## Deploy

Pages is configured to deploy from the `main` branch (root). Pushing to `main`
publishes the change within a minute or so.
